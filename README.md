
# AI-Student-Mentor

## About the Project

AI Student Mentor is an academic support platform designed to help students manage their educational activities efficiently. It provides a simple dashboard to organize subjects, plan study schedules, monitor learning progress, and receive personalized study recommendations.

## Features

- Student Profile Management
- Subject Management
- Study Planner
- Task Management
- Learning Progress Tracking
- AI-Based Study Recommendations
- Data Storage using LocalStorage

## Technologies Used

- HTML – Website Structure
- CSS – Website Styling
- JavaScript – Website Functionality
- Python – Backend Development
- Flask – Backend Framework
- LocalStorage – Data Storage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Enter your student details.
5. Add your subjects.
6. Create study tasks.
7. Track your learning progress.
8. Get study recommendations.

## Backend Setup

1. Install Python.
2. Open the terminal.
3. Navigate to the backend folder.
4. Install the required packages:

   pip install -r requirements.txt

5. Start the backend server:

   python app.py

6. Open http://127.0.0.1:5000 in your browser to check the backend.
